# UI 与设置系统

> **状态**：现行设计。早期「画到引擎 `Output` 上（HUD 之下）」的方案已作废；当前面板画在所有游戏内容之上。

## 0. 一句话

把 NR/SR 参数从「改 config.json + 重启」变成「游戏内面板调、按应用生效」，并用概览集中呈现实时状态。
视觉目标是克制的中性色渲染控制台：字体、间距和状态表达优先于装饰。

## 1. 渲染方案：为什么是 Present 钩子

早期方案有两个代价：HUD 会盖住面板，主菜单不开光追时钩子不跑。当前方案：

- `MinHook` 挂 `IDXGISwapChain::Present`（虚表 8）/ `Present1`（22）/ `ResizeBuffers`（13）/
  `ResizeBuffers1`（39）；
- 钩 `ID3D12CommandQueue::ExecuteCommandLists`（虚表 10）只为拿到游戏的 direct queue；
- `D3D11On12CreateDevice(device12, ..., &gameQueue, 1, ...)` 建 D3D11On12 设备，ImGui 用 DX11 后端；
- 每帧取当前后台缓冲并包装成 D3D11 资源，`AcquireWrappedResources` → 画 → `ReleaseWrappedResources` →
  `Flush` → 真正的 `Present`。

面板因此位于所有游戏内容（含 HUD）之上，主菜单也能开，且不受 `Output` 颜色空间与后处理影响。

## 3. 界面

### 3.1 窗口与视觉层级

- 可拖动浮窗，默认 **980×700** 逻辑单位，初次居中；只有标题条能拖。
- 视口高度不足 1080p 时不低于 1.0 倍，更大视口按高度放大；`[-] 100% [+]` 是用户覆盖。
- 拖动量在 `Begin` 前累计到 `gPos`，窗口和所有子栏同帧使用同一坐标。
- 正文 16px、标题 22px；分区标题使用 Medium 字重。数值输入和统计值保持右对齐。
- 表面使用中性蓝灰；橙色只用于当前选择、未应用修改、主操作和正在操作的控件。
- 普通运行节点不再使用橙色描边；绿色/琥珀/红色只表达运行、等待和错误。
- 设置行按 4/8/12/16/24 的间距节奏组织，不用贯穿分隔线代替层级。

### 3.2 顶部管线

固定五个槽位：

```text
引擎世界 → 神经渲染 / 超分 → 超分 / 神经渲染 → 帧生成 → 输出
```

- 节点显示实际观测值，不读取 `gDraft` 冒充运行结果。
- 世界与输出显示尺寸；NR 显示实际位置和状态；超分显示后端、创建时预设和实际比例。
- 节点是页面入口：世界/输出到概览，NR/SR/FG 分别到对应页面。
- NR/SR 根据实际 `placement` 在中间两个槽位交换。交换使用 0.25 s smoothstep 动画；
  面板刚打开时吸附到实际顺序，不重播。世界、FG 和输出不参与交换。
- **FG 当前只预留位置**，固定显示「未接入」，没有虚构的状态、开关、倍率或配置字段。

### 3.3 页面分工

| 页签 | 内容 |
|---|---|
| 概览 | FPS、帧时间、折线、NR/SR GPU 时间、整体状态、当前后端、渲染/输出尺寸 |
| 神经渲染 | 开关、位置、Style；输入/模型与色调/合成两个默认折叠的高级区 |
| 超分辨率 | 后端对应的可用设置、内部分辨率、模型、抖动、锐化、历史重置 |
| 帧生成 | 仅说明后续入口；当前不实现 FG 功能 |
| 性能 | NR/SR/RCAS GPU 时间与清空计时样本 |
| 设置 | UI 缩放、热键、配置语义 |

概览使用左右两栏和细分隔线；设置页使用完整内容宽度，不再永久携带一栏重复监控数据。
SR 页不重复顶部已有的尺寸和预设读数；锐化 GPU 时间归性能页。

### 3.4 控件

- 普通设置使用「左标签 → 中控件 → 右数值」的同行网格；行宽上限 720，窄行把滑条轨道换到下一行。
- 开关是整行可点的右侧 switch；下拉占据标签右侧剩余宽度。
- 滑条右侧数值是可见输入框。点击后可键入，Enter 或失焦提交；完整解析并 clamp 到范围，
  空串、部分数字、NaN/Inf 回滚，Escape 始终取消。
- NR 的输入/模型和 Ratio 参数默认折叠，功能没有删除。
- SR 抖动是与预设相关的稳定性设置：**K 预设下零最优，M 预设下跟随引擎最优**。
  其他来源与预设的最佳搭配尚未确定；四个来源都是正常选项，不把零当成无条件最优。
- 仅 NR 开关、NR 位置和 SR 抖动保留橙色 `!` 提示；其他必要说明直接 inline，不藏进悬停。

### 3.5 底部操作

顺序为 **放弃 → 保存为默认 → 应用**：

- 「应用」是唯一主按钮，因为是最常用的操作；只写运行时，不落盘。
- 「保存为默认」是次级按钮，应用并写 `config/config.json`；有未应用或未保存修改时可用，保存成功后禁用。
- 「放弃」把 draft 退回运行值。
- 没有未应用修改时，「放弃」和「应用」禁用；一开一关回到运行值会自动恢复无未应用修改，不需要记录碰过的控件。
- 状态分别计算：**未应用** = draft 与运行值不同；**未保存** = 运行值与最近成功写盘的快照不同。
  两者可同时存在；应用后通常显示「已应用 · 未保存」，保存成功后才清除未保存状态。

## 4. 实时读回：面板不替功能代码宣布成功

顶部管线与概览只呈现渲染线程观测。`config.nr.enabled`、`featureCreated`、时间戳对象存在都不能单独证明有帧通过。

NR 状态：

| 状态 | 判据 | 显示 |
|---|---|---|
| `Off` | 设置里关着（唯一一处读设置） | 已关闭 |
| `Configured` | 开了，但 feature 尚未创建 | 已配置 · 未创建 |
| `Created` | feature 已创建，但未观测到帧 | 已创建 · 等待帧 |
| `Running` | `PanelStats::evalCount` 在 2 s 窗口内增长 | 运行中 |

整体状态：

| 状态 | 判据 | 显示 |
|---|---|---|
| `Running` | NR 或超分任一在 2 s 窗口内产出过帧 | 运行中（绿） |
| `Error` | 当下求值失败计数增长，或 NR 创建失败仍无帧 | 运行异常（红） |
| `Waiting` | 菜单、读盘、未创建、NR 被主动关闭等其余情况 | 等待帧（琥珀） |

没有帧只算等待，不算异常；历史累计错误不能在成功出帧后把状态永久钉红。
VV/RT 的超分后端、尺寸与预设来自同一帧快照，管线与概览不得各自推断。

## 5. 输入

- `End` 开关面板（`ui.openKeys`），面板打开时 `Esc` 关闭。
- 热键是组合键；设置页点击按钮后按新组合，Esc 取消或清空（面板键不能为空）。
- 捕获发生在窗口过程，早于 ImGui 与游戏；面板打开时键鼠交给 ImGui，`InputGuard` 同时拦引擎 HID 通路。
- 打开瞬间补发游戏已收到按键的抬起；关闭时由窗口线程收回光标再交还游戏。
- `F11` 始终放行。游戏内热键：`[` NR 开关、`]` 重置 NR + 引擎 DLSS 历史、`F2` 截图。

## 6. 配置语义（暂存式）

- `config/config.json` 只在启动时导入，没有 hot reload。
- 控件编辑 draft；顶部与概览仍显示运行值。
- 最近成功写盘的快照跨面板开关保留；重新打开不会把已应用但未保存的运行值当成磁盘默认值。
- 关闭面板丢弃未应用修改并提示，但不影响已应用未保存的状态。
- **SR 抖动有 `sr.jitterSource` 配置字段**（2026-11-15 用户决定）：与其他控件一样，应用只影响本次运行，保存为默认才持久化；默认值为 `Engine`（跟随引擎）。EXP-0100 中 `Zero` 是已验证稳定值，默认 `Engine` 是用户选择，不代表新的画质实证。
- NR 在关闭状态下「保存为默认」会卸载 feature 和模型；仅「应用」则只停止求值。

## 7. 数据来源

| 面板显示 | 来源 |
|---|---|
| 光栅帧率 / 帧时间 / 折线 | `Overlay` 在 `Present` 里用 QPC 计时，240 点环形历史 |
| 渲染尺寸 / 输出尺寸 | `sr::status()` 每帧快照；RT 映射 `nrPanelStats()`，VV 使用 probe 的 TAAU 声明尺寸 |
| NR GPU / 超分 GPU | 时间戳查询环发布的中位数；没有样本时明确显示「无样本」 |
| 整体状态 | `overallState()`，NR/SR 实际计数与当前错误共同判定 |
| NR 位置与状态 | `PanelStats.placement` 与 `evalCount`；后档创建失败按实际 before |
| 超分后端与比例 | 同一个 `sr::status()` 快照，比例由实测 render/display 尺寸计算 |
| 创建时预设 | VV 取 `vv::dlss::srState().preset`，RT 取 `srPanelStats().preset` |
| SR 抖动控件 | 面板 draft；打开/放弃时从 `config::get().sr.jitterSource` 重读，`vv::sr::syncConfig()` 同步到渲染线程 |

## 8. 实现约束与坑

- 改任何文案后必须跑 `python scripts/collect_glyphs.py`；字集包含所有非 ASCII 字符和全角标点。
- 字体图集在第一帧 `ImGui_ImplDX11_NewFrame()` 构建，面板关闭时也空跑两帧完成预热。
- 无边框 child 必须传 `ImGuiChildFlags_AlwaysUseWindowPadding`，否则文字贴边。
- 软件光标随字号缩放，`MouseCursorScale = 1.3` 保持可见。
- 监控不能寄生在 NR 上：NR 关闭时帧率、尺寸和可用的 GPU 时间仍应工作。
- 清计时样本用 `nrStampClearReported()`；不要在测量窗口重置时清已发布中位数。
- `ResizeBuffers*` 前必须拆掉 11on12 侧所有引用。
