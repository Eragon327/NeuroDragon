4. Why that shows as a frozen frame.
   The draw gate suppresses TAAU on frame N from "frame N-1 injected". If frame N then
   skips injection, nobody writes arg10 in frame N, so that present shows the previous
   arg10 (frozen world) with current UI; the next frame runs TAAU again. Alternating
   injection failure therefore produces exactly "one frozen frame and the current frame
   swapping" at ~40 Hz.

5. Also confirmed in the same session.

   next frame was skipped with fence busy; the engine's arg10 injection path is now
   reachable in-game, which it was not in EXP-0140 (CreateFeature 0xBAD0000B).

   thread) hung again and had to be killed. Remove the per-frame set before the next run.
